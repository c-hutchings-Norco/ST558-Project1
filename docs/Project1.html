Census Data API

The purpose of this project is to create a reusable set of functions that interact with the United States Census Bureau API. Rather than manually downloading data for a specific year, variable, or geographic area, these functions allow users to dynamically request data from the Census Public Use Microdata Sample (PUMS) dataset. The project focuses on four survey years, 2021 through 2024, and demonstrates how metadata can be used to automate variable selection, labeling, and data cleaning.

To accomplish this goal, I first developed a function to retrieve metadata describing the available variables. Next, I created helper functions to convert the raw API responses into usable data structures and to properly interpret coded values. Finally, I combined these components into a larger function capable of requesting, cleaning, and returning Census data in a user-friendly format.

The first step in accomplishing the task is to load libraries that will potentially be used throughout the document. The httr package is used to communicate with the Census API, while jsonlite parses JSON responses into R objects. The dplyr and tidyverse packages provide data wrangling functionality, and lubridate is used to work with time variables. Together, these packages make it possible to collect, clean, and transform the Census data efficiently.

Part 1: Functions

Before requesting data from the API, it is important to understand the available variables and their associated metadata. The Census API provides a file containing descriptions, labels, and possible values for each variable. Since some variable names differ across survey years, I created a function that automatically retrieves the correct metadata and selects only the variables relevant to this project.

#Create a function to get all the variables named funcation variable list (fun_var_list)
fun_var_list <- function(year) {
  
  # Exclude any years outside of the following    
  if (!year %in% c(2021, 2022, 2023, 2024)) {
    stop("Year must be 2021, 2022, 2023, or 2024.")
  }
  
  # Use the API to get the data, use paste to add the year as a variable determined by the function    
  response <- GET(
    paste0("https://api.census.gov/data/",
           year,
           "/acs/acs1/pums/variables.json"))
  
  # Parse the data from JSON  
  parse_var <- fromJSON(rawToChar(response$content))
  
  # Pull out the variables required.  Choose the names depending on the year requested because they change for certain years.  
  
  if (year %in% c(2021, 2022)) {
    required_vars <- c("AGEP", "GASP", "GRPIP", "JWAP", "JWDP", "JWMNP", "PWGTP", "FER", "HHL", "SCH","SCHL", "SEX", "ST", "REGION", "DIVISION")
    
  } else {
    required_vars <- c("AGEP", "GASP", "GRPIP", "JWAP", "JWDP","JWMNP", "PWGTP", "FER", "HHL", "SCH", "SCHL", "SEX", "STATE", "REGION", "DIVISION")
  }
  
  #create a list that includes only the required variables.    
  var_list <- parse_var$variables[required_vars]
  
  #return the list  
  return(var_list)
}

Helper Function to Parse Data

The raw API response is returned as JSON, which is not a user friendly format for statistical analysis. Once the JSON response was parsed, I explored the organization of the returned dataset and identified that the API stores column names in the first row rather than as traditional variable names. The remaining rows contained the actual observations. Recognizing this pattern allowed me to develop a helper function that systematically extracts the column names and converts the data into a clean tibble ready for analysis.

#Helper function to create a tibble from parsed data
helper <- function(parsed_data){
  new_tibble <- as_tibble(parsed_data[-1, ], 
                          .name_repair='minimal')
  names(new_tibble) <- parsed_data[1, ]
  return(new_tibble)
}

Several Census variables record times using coded intervals rather than exact clock times. For example, a code may represent an arrival time between two specified hours. To make these variables easier to analyze, I created a helper function that converts each interval into its midpoint. This provides a single representative time while preserving the overall timing information contained in the original data.

Helper Function to find Midpoint Time

Create the time helper function that finds the midpoint of the time in the given time interval. There are several different variables available to test the time helper function on. One of the variables JWMNP is essentially a null value variable as the only value is they did not travel to work that day. I removed the day portion of the time/date variable since this information was not provided and only returned the hour:minute:second portion of the date/time value.

#loading the all variables object so the items can be used to identify the labels for the variables.
all_var_list <- readRDS("data/variable_list.RDS")


#Create the helper time function
helper_time <- function(code, var_name, year_metadata){
  #code 0 as NA based on the item for the value
  if(is.na(code) || code == "0"){
    return(NA)
  }
  #Pull the label from the variable using its value
  label <-
    year_metadata[[var_name]]$values$item[[as.character(code)]]
  
  if(is.null(label)){
    return(NA)
  }
  #Format the time into a usable format by removing to and fixing p.m.
  times <- strsplit(label, " to ")[[1]]
  times <- gsub("\\.","", times)
  
  start <- parse_date_time(times[1], "I:M p")
  end   <- parse_date_time(times[2], "I:M p")
  
  #Finding the midpoint of the two times in the label
  midpoint <- start + (end - start)/2
  
  #Return the midpoint in hour and minute format
  return(hm(format(midpoint, "%H:%M")))
}

# Create a factor helper function
helper_factor <- function(x, labels){
  factor(
    x,
    levels = names(labels),
    labels = unlist(labels)
  )
}

Function to Use API

After creating the helper functions, I combined them into a single function that retrieves Census data and returns a cleaned tibble. The function includes default values, validates user inputs, and automatically selects the correct metadata for the requested year.

Because the state variable is named ST in 2021 and 2022 but STATE in 2023 and 2024, the function adjusts automatically based on the survey year. After downloading the data, it converts numerical variables, applies midpoint calculations to time variables, and converts categorical variables into labeled factors.

api_key <- "96f181e4ada2cf8ebea839ffd9fa684508d8fc09"


#create a function to get the data from the api and create a tibble.
get_api_data <- function(
    #default values
  year = 2024,
  num_var = "AGEP",
  cat_var = "SEX",
  geography = "State",
  geo_value = NULL){
  
  # Check year is in the given 4 years
  if(length(year) != 1 ||
     !year %in% c(2021, 2022, 2023, 2024)){
    stop("Year must be 2021, 2022, 2023, or 2024")
  }
  
  # Select metadata year
  if(year == 2021){
    year_metadata <- all_var_list$variables_21
  } else if(year == 2022){
    year_metadata <- all_var_list$variables_22
  } else if(year == 2023){
    year_metadata <- all_var_list$variables_23
  } else {
    year_metadata <- all_var_list$variables_24
  }
  
  # Check numeric variable is one of the set variables
  allowed_num <- c(
    "AGEP",
    "GASP",
    "GRPIP",
    "JWAP",
    "JWDP",
    "JWMNP"
  )
  
  if(length(num_var) != 1){
    stop("Specify exactly one numeric variable")
  }
  
  if(!num_var %in% allowed_num){
    stop("Invalid numeric variable")
  }
  
  # PWGTP always included
  api_vars <- c(num_var, "PWGTP")
  
  # Check categorical variable is from given list
  allowed_cat <- c(
    "FER",
    "HHL",
    "SCH",
    "SCHL",
    "SEX"
  )
  
  if(length(cat_var) != 1){
    stop("Specify exactly one categorical variable")
  }
  
  if(!cat_var %in% allowed_cat){
    stop("Invalid categorical variable")
  }
  #define the available variables to choose from
  api_vars <- c(api_vars, cat_var)
  
  # Check geography is one of the values specified
  allowed_geo <- c(
    "Region",
    "Division",
    "State"
  )
  
  if(length(geography) != 1){
    stop("Specify exactly one geography level")
  }
  
  if(!geography %in% allowed_geo){
    stop("Geography must be Region, Division, or State")
  }
  
  # Default geography value
  if(is.null(geo_value)){
    
    geo_defaults <- c(
      State = "06",
      Division = "9",
      Region = "4"
    )
    
    geo_value <- unname(
      geo_defaults[geography]
    )
    
  }
  
  # Validate geography value
  if(geography == "State"){
    
    if(year %in% c(2021, 2022)){
      geo_var <- "ST"
    } else {
      geo_var <- "STATE"
    }
    
  } else {
    
    geo_var <- toupper(geography)
    
  }
  
  
  valid_geo <- names(
    year_metadata[[geo_var]]$values$item
  )
  
  if(tolower(geo_value) != "all" &&
     !geo_value %in% valid_geo){
    stop("Invalid geography value")
  }
  
  # Build URL
  if(tolower(geo_value) == "all"){
    
    url <- paste0(
      "https://api.census.gov/data/",
      year,
      "/acs/acs1/pums?get=",
      paste(api_vars, collapse = ","),
      "&for=",
      tolower(geography),
      ":*",
      "&key=",
      api_key
    )
    
  } else {
    
    url <- paste0(
      "https://api.census.gov/data/",
      year,
      "/acs/acs1/pums?get=",
      paste(api_vars, collapse = ","),
      "&for=",
      tolower(geography),
      ":",
      geo_value,
      "&key=",
      api_key
    )
    
  }
  
  response <- GET(url)
  
  parsed <- fromJSON(
    rawToChar(response$content)
  )
  
  census_tbl <- helper(parsed)
  
  # Convert numeric/time variable
  if(num_var %in% c(
    "JWAP",
    "JWDP",
    "JWMNP")){
    
    census_tbl[[num_var]] <- sapply(
      census_tbl[[num_var]],
      helper_time,
      var_name = num_var,
      year_metadata = year_metadata
    )
    
  } else {
    
    census_tbl[[num_var]] <-
      as.numeric(census_tbl[[num_var]])
    
  }
  
  # Convert PWGTP
  census_tbl$PWGTP <-
    as.numeric(census_tbl$PWGTP)
  
  # Convert categorical variable
  labels <- year_metadata[[cat_var]]$values$item
  
  census_tbl[[cat_var]] <-
    helper_factor(
      census_tbl[[cat_var]],
      labels
    )
  
  # Add census class
  class(census_tbl) <-
    c("census", class(census_tbl))
  
  return(census_tbl)
  
}

Create a Function for Multiple Years

To allow data from multiple years to be analyzed together, I created a function that repeatedly calls the single-year function and combines the results. A year variable is added to each dataset before the data are merged, making it possible to identify the source year of each observation.

# Create a function that combines more than 1 year
get_api_data_multi <- function(
    years,
    num_var = "AGEP",
    cat_var = "SEX",
    geography = "State",
    geo_value = NULL){
  
  #set table to empty
  final_tbl <- NULL
  #create a loop to go through for each given year.
  for(year in years){
    
    temp <- get_api_data(
      year = year,
      num_var = num_var,
      cat_var = cat_var,
      geography = geography,
      geo_value = geo_value
    )
    
    temp$year <- year
    
    #first pass fill the table with the temp each additional pass append the new data to the table.
    if(is.null(final_tbl)){
      final_tbl <- temp
    } else {
      final_tbl <- bind_rows(final_tbl, temp)
    }
    
  }
  
  return(final_tbl)
  
}

Summaries for Numerical and Categorical Variables

#create a function to calculate the weighted mean
get_mean_function <- function(numeric_vector, weight_vector){
  wt_mean = sum(numeric_vector*weight_vector)/sum(weight_vector)
  
  return(wt_mean)
}

#create a function to calculate the standard devaition using the weighted mean function
get_sd_function <- function(numeric_vector, weight_vector){
  #call the mean function to find the mean
  calculated_mean <- get_mean_function(numeric_vector, weight_vector)
  
  wt_sd <- sqrt(
    sum(numeric_vector^2*weight_vector)/sum(weight_vector)-calculated_mean^2)
  
  return(wt_sd)
}

Function for Summaries

summary.census <- function(census_tib, 
                           num_var= NULL, 
                           cat_var= NULL){
  #if numeric remains null, all variables will be used
  if(is.null(num_var)){
    num_var <- c("AGEP", "GASP", "GRPIP")
  }
  
  #if categorical remains null, all variables will be used
  if(is.null(cat_var)){
    cat_var <- c("FER", "HHL", "SCH", "SCHL", "SEX", "year")
  }
  
  output <- list()
  
  for(var in num_var){
    #check for variables that are in the tibble
    if(var %in% names(census_tib)){
      
    output[[paste0(var, "_mean")]] <- get_mean_function(
      census_tib[[var]], census_tib$PWGTP
    )
    output[[paste0(var, "_sd")]] <- get_sd_function(
      census_tib[[var]], census_tib$PWGTP
    )
    }
  }
  for(var in cat_var){
    #check for variables in census tibble
    if(var %in% names(census_tib)){
      
    output[[var]] <- table(census_tib[[var]])
    }
  }
  return(output)
}
